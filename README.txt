README – Vineyard Biodiversity MSc Analysis
Project Overview

This folder contains data and R scripts for Hannah Friesen's MSc chapter 2 research on vineyard biodiversity in the Okanagan Valley, BC. The research investigates:

How ground-dwelling arthropods (carabid beetles and spiders) abundance and richness vary in response to vineyard management, vegetation properties and landscape heterogeneity.

Data Description

Pitfall traps (traps_set)

Each row = one pitfall trap with unique ID (e.g., PF001).

Key variables: pitfall_ID, sample_ID, site_ID, habitat, sample_period, date_collected.

Spider data (spider_data_VY.csv)

Total abundance and family-level richness counts, summarized by site, habitat and year.

Carabid data (carabid_data_VY.csv)

Total abundance and species-level richness counts, summarized by site, habitat and year.

Management data 

Organic vs conventional vineyards

Vegetation data

Quadrat-level vegetation measurements (cover, height, richness), summarized by site, habitat and year.

Key variables: site_ID, habitat, avg_veg_height, avg_veg_cover, veg_richness.

Landscape data

Landscape metrics (e.g., proportion natural habitat, distance to nearest natural habitat).

Extracted at multiple buffer scales (100 m, 250 m, 500 m, 700 m, 1000 m).

Environmental data

Coordinates, elevation, aspect, slope and soil organic carbon. 


Software & Dependencies

All analyses were conducted in R (≥4.5.2).


Main packages:

tidyverse (data wrangling, plotting)

glmmTMB (generalized linear mixed models)

DHARMa (model diagnostics)


Scripts include library() calls for required packages.


Notes

Outlier handling, sensitivity tests, and model selection are documented in each analysis script.

Spatial autocorrelation tests were run using DHARMa.
